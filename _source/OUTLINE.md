## The outline sent to RSM (Reem Alarbeed, 2 Nov 2026; reposted by Moudhi Albannai, 3 Nov 2026)

**Day 1: Designing AI Agents for Real Work**
Objective: Identify and build a working AI agent that replaces a real task from daily work.
- Reframing Work: Identify repetitive tasks across audit and onboarding workflows
- Agent Design Framework: Define input, instruction, and output
- Use Case Selection: Choose one real use case (analysis, extraction, workflow, reporting)
- Build (Using Claude): Create a working agent that solves the selected task

**Day 2: Turning Agents into Operational Workflows**
Objective: Convert the agent into a repeatable, automated workflow.
- From Agent → System: Introduce triggers, workflows, and integrations
- Workflow Build (Using n8n): Connect input → AI → output
- Customization: Adapt the solution to department-specific needs
- Demo & Next Steps: Present solution and identify what to automate next

Suggested tools: n8n and Claude.
