Take-home guide

Repeat what you built, on your own work, safely. Two weeks from one task to a decision.

Week 1 · Day 1
Pick one task
  1. Use the four questions on your own task list.
  2. Choose a task with written rules and a digital input.
  3. Ask your manager: which tool and which data are approved for it?
Week 1 · Day 2
Write the Agent Card
  1. Fill every line: input, instruction, output, three tests.
  2. Ask a colleague: could a new joiner run this card?
Week 1 · Day 3
Build version 1
  1. Build it in the firm-approved Claude account.
  2. Start with practice or public data. Use real files only if the policy allows it.
Week 1 · Days 4 and 5
Test and fix
  1. Run the three tests. Write the expected answer first.
  2. Fix the instruction, not the answer. Keep a test log.
Week 2
Pilot with a reviewer
  1. Run it on real cases next to the normal process.
  2. A reviewer checks every output. Note the minutes before and after.
  3. At the end of the week, decide: keep, change or stop.
After the pilot
Make it a workflow
  1. Ask IT to connect the trigger and the output to the firm's systems.
  2. Agree five things first: owner, test set, review rule, data rule and log.
When to stop
Three signs a task is not ready
  1. The agent guesses even after you fix the instruction.
  2. Reviewers need more time to check it than to do the task.
  3. The task needs data the policy does not allow in the tool.
