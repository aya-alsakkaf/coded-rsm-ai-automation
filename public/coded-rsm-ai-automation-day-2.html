Turning Agents into Operational Workflows

Package your own method as a skill, turn one file into a dashboard and a deck, put your skill on a schedule, see where n8n and Power Automate fit, then build an agent for one department.

Day 2 of 2 · Monday 16 Nov 08:30-15:30 In person · CODED, Alsharekh classroom (Frontend Campus)
The day in one line · 08:30-15:30

Day brief

Day 2 starts with skills: your own task, written once and used anywhere. Then artifacts: a KPI dashboard and a presentation from one file. Then a scheduled task runs your skill without you. After lunch you see what Claude cannot do yet and where n8n and Power Automate take over, with a short n8n demo. The afternoon is yours: a mini project that builds an agent for one department, start to finish.

You build today: Your own skill, a dashboard and a deck, a scheduled task, and an agent for one department.

What you will be able to do

  • Explain how a prompt, Project instructions, a skill and an agent differ, and why you combine them.
  • Turn your own task into a skill and check that Claude picks it.
  • Build a KPI dashboard and a presentation from one file, and check the numbers.
  • Run your skill on a schedule, with a run log.
  • Say when a task needs n8n or Power Automate, using trigger, node and output.
  • Build and show an agent for one department.
