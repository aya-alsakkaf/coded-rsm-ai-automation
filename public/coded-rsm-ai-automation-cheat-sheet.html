Part 2 · The five-part instruction
Write the Instruction box in five parts
The invoice agent as the example.
Role
Who Claude is
You are an audit associate at Mirqab & Co. You match a client's supplier invoices to its purchase ledger.
Steps
What to do, in order
1. Read every invoice in the pack. 2. Find each invoice number in the purchase ledger. 3. Compare the date and the amount in KWD.
Rules
What must always be true
Use only the attached files. Show amounts in KWD with three decimals. Never round, change or convert an amount. Any difference of 0.001 or more counts.
Output format
The exact shape
One table in the columns of the template in the project knowledge. Status is one of: Matched, Amount differs, Not in ledger, Not found.
When unsure
What to do with a gap
If a field is missing or unclear, write Not found and explain it in the Note column. Never guess.

Part 3 · Build it in Claude
Where each part lives
Menu names as of November 2026.
Project
Instruction and knowledge
Projects, + New Project, Set project instructions, then + for knowledge files.
Rules in the instructions, templates in knowledge; documents come with each run.
Connector
Input
Customize, then Connectors, then Google Drive. Sign in.
It reaches every file the account can open. Use an account that opens only what the task needs.
Artifact or file
Output
Ask for an artifact or an Excel file with exact columns and a total line.
Same columns, same order, every run.
Skill
Package
Ask Claude to turn the Project into a skill. Find it under Customize, then Skills.
Code execution and file creation must be on.
Scheduled task
When
Click Scheduled in the left sidebar, then New task, then Set up manually. Name, prompt, approval mode, frequency. Run it once on demand to test.
Runs remotely when it uses Drive; uses connectors and skills.
Each Claude feature fills one box of the card.
Part 4 · Run rules
Before anything runs on its own
The rules every team added on Day 2.
Inbox, then Processed
Changing inputs
Read new files in the Inbox; move each one to Processed.
Nothing is read twice.
Empty folder
No new files
Write No new files in the run log and stop.
Never process old files to fill a gap.
Drafts only
Review step
Mark the output DRAFT. End with Reviewed by.
A person signs off.
Run log
One file per run
runlog-YYYY-MM-DD-HHMM.txt in Log: date, files read, items flagged, file saved.
Read it every morning.
Owner
A named person
Every workflow has one owner and one reviewer.
Who runs it when you are on leave?
Flag, never guess. Drafts, never final.
