Cheat sheet

The framework, the instruction, the tests and the workflow skeleton, on one page.

Part 1
The framework

Every agent has three parts. Get these right and the tool matters much less.

InputWhat it reads each timeName the file, the fields and the format.The KYC pack as one PDF.
InstructionHow it does the jobRole, steps, rules, what to do when unsure, output.Check Section 2 of the policy. Flag expiry within 60 days.
OutputWhat a reviewer getsA fixed format a person can check in two minutes.Required document | Status | Evidence | Note
The agent does the first pass. You sign the file.
Part 2
Five parts of a strong instruction

Each part removes one way the agent can guess.

RoleWho it isName the job and who it serves.You are a client onboarding assistant at the firm.
StepsIn orderNumber them. One action per step.1. List every document. 2. Compare with Section 2.
RulesThe limitsSources it may use, thresholds, what it must never do.Use only this pack and the policy.
If unsureNo guessingTell it what to write when the answer is not there.Write Not found. Never guess a date.
OutputThe formatColumns or sections, in order, and a last line.A table, then one decision line.
Part 3
Test before you trust

Write the expected answer before you run each test.

NormalEverything is thereDoes it say so, without inventing problems?
Missing dataOne item is not thereDoes it write Not found, or does it fill the gap?
TrapLooks fine, breaks a ruleDoes it catch the near miss?
When the answer is wrong, fix the instruction, not the answer. Then run all three tests again.
Part 4
Find the task

Four questions. Four yes answers: automate. Two or three: assist. One or none: keep it human.

1Does it repeat?Weekly or more.
2Are the rules written down?A policy, a memo, a checklist.
3Is the input digital?A file, a table, an email.
4Can a reviewer check it in 2 minutes?A table, not an essay.
Part 5
The workflow skeleton

Trigger → Read → AI → Decide → Output. The human check sits after Decide.

TriggerOn form submissionAlso: email, a new file in a folder, a schedule.
ReadExtract from FileExtract From PDF or From XLSX. Add Aggregate for many rows.
AIBasic LLM ChainWith the Anthropic Chat Model and a Structured Output Parser.
DecideIFReads one field, for example status.
OutputData table, Form EndingA row for the reviewer, a line back to the sender.
