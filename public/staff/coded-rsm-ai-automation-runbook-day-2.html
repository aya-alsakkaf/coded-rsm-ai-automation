  • Customize, then Connectors: Google Drive is connected before Day 1 with the trainer's CODED training Google account. Open the sandbox folders once. Demo 1.6 only shows the connector.
  • Before each day: run one scheduled task unattended (laptop closed) on a test folder, not a demo Inbox, with the approval mode set so it can save and move Drive files. Check the output file and the run-log file in Log, and that the inputs moved to Processed with no approval request waiting.
  • Daily schedules run every day. Kuwait works Sunday to Thursday, so Friday and Saturday runs log No new files. Check this on the first weekend run.
  • Confirm the names on the Scheduled page (New task, Set up manually, the approval mode, running a task on demand). If a name changed, say the new one in the room.
  • Open this runbook, the backup results and the answer key on your own screen. Test the projector with the deck at full screen (F).
  • Day 2: Demo 2.1 opens mirqab-invoice-match on the trainer account (Customize, then Skills). Demo 2.2 attaches mirqab-engagement-portfolio-2026.xlsx (lab step 3).
  • Day 2, before 12:40: open the n8n video (the file on the Demo 2.4 slide) and the n8n workflow Mirqab · invoice routing. The video has no sound: you talk over it.
  • Day 2: no connectors on the trainees' accounts. Demo 2.3 attaches the October invoices and ledger (Day 1 lab, step 2) and adds them to mirqab-invoice-match as reference files before scheduling it.

02Task 2.1 · Claude · skillsYour turn · 25 min · on your own

A skill for your own task

No file needed.
▶Say“Your own task this time, not the invoices. Struggle first; a hint at 8 minutes.”
  1. Open your Agent Card (Day 1 lab page, step 4), or your strongest task from Task 1.3.
  2. New chat: paste Turn my task into a skill (prompt sheet, Task 2.1) with your card. Answer the questions.
  3. Save the skill. Check it under Customize, then Skills. Then send Make a test file.
  4. New chat: attach the test file and ask for your task in one line. Skill used? Both problems flagged?
Prompts: paste in this order
Turn my task into a skillHelp me build a Claude skill for a task I repeat at work. My Agent Card, with no client or firm names: [paste your card]. Ask me up to five questions first. Then write the skill: a short lowercase name with hyphens, a one-line description of when to use it, the steps, the rules, the output columns in order, and When unsure (write Not found, never guess). Make it a skill file I can save.
Make a test fileMake a fictional test file for this skill: [file type, for example an Excel sheet] with 10 to 15 rows and 2 planted problems the skill should flag. Use made-up names and amounts only. Do not tell me where the problems are.
What you should seeA saved skill with a short name and a one-line description; a fresh chat that names the skill, returns the fixed shape and flags both planted problems.
+Finished earlyShare the skill with a colleague: Customize, then Skills, the ... menu, then Share.
!If it failsIf saving fails, keep the skill text, run it as Project instructions for now, and the trainer helps at the break. Code execution must be on (Settings, then Capabilities). The result is on the backup results page.
◆Land thisA skill is your method, written once, used anywhere.
