Task 2.1

Your own skill, saved and tested in a fresh chat on a fictional test file.
Task 2.1 · 25 min · on your own

A skill for your own task

No file
Hint (the participant pages show this)If Claude does not use your skill, make its description name the task and the file type.
Answer

Approve a skill when

  • The name is short and clear.
  • The description names the task and the file type.
  • It has steps, at least two rules, the output columns and a When unsure line.
  • No client names or real data: it can be shared.
  • A fresh chat names the skill and flags both planted problems.
