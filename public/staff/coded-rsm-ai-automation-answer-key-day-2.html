Task 2.5

A Log folder with three clean runs and the failed-run test, and a rehearsed 5-minute demo with its impact number.
Task 2.5 · 40 min · in your team

Clean runs, a failed run and the script

mirqab-locked-test-file.pdf
Hint (the participant pages show this)Every number on your demo comes from your run log or the Clock tab.
Answer

The failed-run test

  • The run log names mirqab-locked-test-file.pdf as Could not read. Nothing is guessed, and the file stays in the Inbox.
  • If the log is silent or a row has values, the fallback line is missing from the prompt: add it and run on demand again.
  • The fallback for a real file: the named reviewer checks it by hand, and the team asks for a readable copy.
