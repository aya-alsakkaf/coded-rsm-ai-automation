The invoice version

Use the mirqab-invoice-match skill. Read the new files in Google Drive: Mirqab sandbox / 01 Invoices / Inbox. Save the result as an Excel file in 01 Invoices / Outputs, named abdali-invoice-match-YYYY-MM-DD-HHMM.xlsx, with the date and time of the run. Move each file you read to 01 Invoices / Processed. Save a run-log file in 01 Invoices / Log, named runlog-YYYY-MM-DD-HHMM.txt, with one line: date, files read, items flagged, file saved. Lesson 4 · Fit it to your department · Task 2.5

Your department's rules

Claude · skills · input: mirqab-review-rules.docx

The rules file

Assurance

  • A difference over KWD 100 goes to the supervisor for review.
  • Never post or propose an adjustment: flag it with the evidence.
  • Amounts in another currency are flagged, never converted.

Corporate Finance

  • Every figure in a summary shows its source file and cell.
  • Projections are labeled draft until a senior associate reviews them.

Support

  • Follow-ups to clients are drafts only. A person reads and sends them.
  • Use the client's name and the request number in every follow-up.

Analytics Advisory

  • Every chart or table names its period and its source.
  • Movements are flagged on both rules: over 10% and over KWD 5,000.

All departments

  • Outputs are named client-task-YYYY-MM-DD-HHMM.
  • Each run saves one run-log file in Log: date, files read, items flagged, file saved.
  • If there are no new files: write No new files in the run log and stop.
