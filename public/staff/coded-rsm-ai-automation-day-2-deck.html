Expressions

Expressions move data from one step to the next.

{{ $json['Your question'] }}The field Your question, from the step just before.
{{ $('On form submission').item.json['Client name'] }}A field from a named step further back.
{{ $json.text }}The text the AI or the file reader returned.

Do not type them. Drag the field from the input panel on the left into the box, and n8n writes the expression.

OutputForm Ending

The summary line, back to the person who sent the form.

Structured output

Ask for fields, not paragraphs.

A paragraph · the IF cannot read it

The pack is not complete. The license seems to be expired and one document may be missing, so it would be best to review it before accepting.

Named fields · the IF reads status

{
  "client": "Example Client W.L.L.",
  "status": "Needs review",
  "items_to_resolve": 2,
  "issues": ["Example: Articles of association missing (no page)", "Example: Signatory ID copy expires within 60 days (page 4)"],
  "risk_flags": ["Example: Section 4(a), company shareholder registered outside Kuwait (page 3)"],
  "summary": "Not ready: 2 items to resolve"
}

An IF cannot read a paragraph. It can read one field: status. A Structured Output Parser makes Claude fill the fields.

Department-specific

What changes for audit and for onboarding.

Audit

  • Materiality and thresholds from the memo
  • The year-end date and the cut-off test
  • The sample, and how it was picked
  • The reviewer: the senior, then the manager

Onboarding

  • The document list for each type of entity
  • The expiry window: 60 days
  • The high-risk indicators, and who approves
  • Sanctions and PEP screening stays in the firm's approved system

Both: a named reviewer, a log of every run, and no client data outside approved tools.
