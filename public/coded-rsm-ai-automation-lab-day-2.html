Step 1

A skill for your own task (Task 2.1)

  1. Open your Agent Card from yesterday (Day 1 lab page, step 4). No card? Use your strongest task from Task 1.3.
  2. In Claude, click New chat. Paste Turn my task into a skill from the prompt sheet (Day 2 page → Open the prompt sheet), Task 2.1, with your card in the brackets. Answer Claude's questions.
  3. Save the skill when Claude shows it. Check it is listed: Customize, then Skills.
  4. In the same chat, send Make a test file. Download it.
  5. Click New chat, attach the test file, and ask for your task in one line.
Show a hint

If Claude does not use your skill, make its description name the task and the file type.

Saved in this browser only. The trainer checks it with you.
Step 2

Will Claude pick your skill? (Task 2.2)

  1. New chat: ask for your task in your own words. Did Claude use your skill?
  2. New chat: the same task in different words.
  3. New chat: something unrelated, such as an email. The skill should not load.
  4. If a test failed, send Sharpen the description from the prompt sheet (Day 2 page → Open the prompt sheet), Task 2.2. Save the skill again and repeat.
Show a hint

Name the task and the file type in the description.

Saved in this browser only. The trainer checks it with you.
Step 3

Your KPI dashboard (Task 2.3)

  1. Pick one department pack below and download it, or use your Task 2.1 test file. The first file is the trainer's demo file.
  2. In Claude, click New chat and attach the file. Paste the Dashboard request from the prompt sheet (Day 2 page → Open the prompt sheet), Task 2.3, and fill the brackets.
  3. Check three KPI tiles by hand in Excel. Then send Check it.
  4. Ask for one change and watch the dashboard update.

Step 5

Schedule your skill (Task 2.5)

  1. New chat: attach your test file. Paste Add my file to the skill from the prompt sheet (Day 2 page → Open the prompt sheet), Task 2.5. Save the skill again.
  2. Click Scheduled in the left sidebar, then New task, then Set up manually.
  3. Paste the Scheduled task prompt from the prompt sheet (Day 2 page → Open the prompt sheet), Task 2.5. Fill the brackets.
  4. Weekly, Sunday at 08:00. Save. Run it once on demand.
  5. Open the run on the Scheduled page: the first line, then your output.
Show a hint

If the run says the file is missing, the file is not inside the skill yet.

Saved in this browser only. The trainer checks it with you.
Step 6

Claude or an automation tool? (Lesson 4)

  1. Think of one task in your department that starts with an event: an email arrives, a form is sent, a file lands.
  2. Write it below with the tool you would use (Claude, n8n or Power Automate) and one reason.
  3. Watch the n8n demo video: name the trigger, the steps and the outputs.
  4. Finished early? Paste Plan my workflow from the prompt sheet (Day 2 page → Open the prompt sheet), Demo 2.4, with your task. Claude describes it; nobody builds it today.
