Put your workflow on a schedule

Your team works through these steps today. Each person can keep their own notes here; the team's card goes on the shared board.

7 steps A check on each step Saved in this browser
0 of 7 done
Step 1

The workflow card (Task 2.1)

  1. Fill When, Input, Skill, Output and Who reviews for your team's agent.
  2. Post it on the shared board.
Show a hint

Who reviews is one person's name.

Saved in this browser only. The trainer checks it with you.
Step 2

Create the scheduled task (Task 2.2)

  1. Work on the laptop of the person who made your team's skill. Copy your track pack into your team folder's Inbox.
  2. Click Scheduled in the left sidebar, then New task, then Set up manually. Paste the prompt from the prompt sheet and fill the brackets.
  3. Approval mode: let the run save and move files without waiting. Daily at 08:00. Save. Run it once on demand.
Show a hint

Most failures are a folder name that does not match the Drive.

Saved in this browser only. The trainer checks it with you.
Step 3

Batch 2 (Task 2.3)

  1. Workflow teams: add the request list to the skill and the tracker line to the prompt. Analysis teams: add the monthly line.
  2. Copy your track's batch-2 file from Packs into the Inbox.
  3. Run the task on demand. Check the output and the run log.
Show a hint

Each track's batch-2 file holds one change the run must show.

Saved in this browser only. The trainer checks it with you.
Step 4

The empty folder

  1. Empty the Inbox. Run the task on demand.
  2. Read the run log.
Show a hint

One honest line, then stop.

Step 5

Department rules (Task 2.4)

  1. Pick two rules from mirqab-review-rules.docx.
  2. The skill owner adds them to the skill word for word, with DRAFT and Reviewed by.
  3. Copy your track's messy file into the Inbox. Run the task on demand.
Show a hint

A paraphrase is a new rule. Copy them exactly.

Saved in this browser only. The trainer checks it with you.
Step 6

Clean runs and the failed-run test (Task 2.5)

  1. Copy your pack into the Inbox and run on demand. Do it three times. Workflow teams: move the trackers in Outputs to Processed before each run.
  2. The skill owner adds the fallback line from the prompt sheet to the scheduled task's prompt.
  3. Copy mirqab-locked-test-file.pdf from Packs into the Inbox. Run on demand. Read the run log.
  4. Delete the locked file from the Inbox.
Show a hint

A good run says what it could not do.

Step 7

Impact and the demo (Task 2.5)

  1. Impact: (minutes by hand minus minutes with the agent) times runs a month.
  2. A 5-minute plan: problem, card, live run, impact, next.
Show a hint

Every number on your demo comes from your run log or the Clock tab.

Saved in this browser only. The trainer checks it with you.
