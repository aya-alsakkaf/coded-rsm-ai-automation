Designing AI Agents for Real Work

Find the task that repeats every week, describe it as an Agent Card, and build it in Claude, one box at a time.

Day 1 of 2 · Sunday 15 Nov 08:30-16:30 In person · CODED, Alsharekh classroom (Frontend Campus)
The day in one line · 08:30-16:30

Day brief

Day 1 starts with what AI is and where it fails, with two real cases. Then 18 people do the same task and get 18 different tables. You learn to write a good prompt and what an agent is, find the tasks worth an agent, write an Agent Card, and build your own agent in Claude: a Project, a Drive folder, a fixed-shape output and a skill.

You build today: Your own agent: an Agent Card, a Project, a connected folder, a fixed-shape output and a skill.

What you will be able to do

  • Explain why AI can give a confident figure that is wrong, and tick it against the source.
  • Write a five-part prompt that gets an exact, checkable answer.
  • Find the tasks in your work that suit an agent, and write an Agent Card.
  • Build a Claude Project that gives the same, checkable table every run.
  • Read from a Drive folder and return a fixed-shape output.
  • Package your method as a skill you can share.
