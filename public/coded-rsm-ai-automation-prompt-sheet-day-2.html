Task 2.2Claude · skillsYour turn · 8 min

Will Claude pick your skill?

  1. Click New chat. Ask for your task in your own words, with the test file. Did Claude use your skill?
  2. Click New chat. Ask for the same task in different words. Did it use the skill again?
  3. Click New chat. Ask for something unrelated, such as an email. The skill should not load.
  4. If a test failed, send Sharpen the description from the prompt sheet (Day 2 page → Open the prompt sheet), Task 2.2, save the skill again and repeat the test.
You hand in

Three test chats and, if needed, a sharper description.

Sharpen the description
Here is my skill's description: [paste it]. Rewrite it in one or two sentences so Claude uses the skill for [my task] with [file type], and not for other requests. Keep it under 200 characters. Then update the skill so I can save it again.
Finished early? Extra task
  • Ask a neighbor to request your task in their own words. Does your skill load for them on your laptop?
What to look forName the task and the file type in the description.

Lesson 2 · Artifacts

Demo 2.2Claude · artifactsWatch, then try

A KPI dashboard, then a deck

Watch it in the slide. The trainer runs it with the room.
Dashboard request
Role: You are a reporting analyst at Mirqab & Co. Data: the attached engagement portfolio. Build an interactive dashboard artifact for the partners. KPI tiles at the top: total fee, billed as % of fee, collected as % of billed, hours used as % of budget, engagements over budget, reports overdue (due before 16 November 2026 and not Closed). Charts: fee by service line; budget against actual hours by engagement. A table of engagements that are At risk or Delayed. A filter by service line. Rules: use only the file and calculate with code. If a value is blank or does not make sense, leave it out of that KPI and list it under Data issues. Never guess. Show the date of the data.
Deck request
Turn this dashboard into a 5-slide presentation for Monday's partners' meeting: a title, the KPIs, what is at risk, the data issues, and the decisions we need. Use only the dashboard's figures. One idea per slide.
What to look forEvery KPI tile must match the file. The two data issues must be listed, not hidden.
Files
mirqab-engagement-portfolio-2026.xlsx
TakeawayAsk for the audience, the KPIs with their formulas, the layout and the rules.

Schedule your skill

  1. New chat: attach your Task 2.1 test file (or your pack file). Send Add my file to the skill (prompt sheet, Task 2.5). Save the skill again.

  4. Frequency: weekly, Sunday at 08:00. Save. Run it once on demand.
  5. Open the run on the Scheduled page: the first line, then your output.

Lesson 5 · Mini project

Task 2.6Claude · everythingYour turn · 85 min

Mini project: your department's agent

  1. Card (10 min): pick a pack (step 7 of the Day 2 lab page) or your own task. Fill the Project card from the prompt sheet.
  2. Build (25 min): a Project with five-part instructions, then a skill.
  3. Output (20 min): a dashboard or report, its layout written in the skill.
  4. When (15 min): the file inside your skill, then a scheduled task run once on demand.
  5. Check (15 min): three figures, DRAFT and Reviewed by, impact, demo script.
You hand in

Your department agent: Project, skill, artifact, a scheduled task run once, three figures checked, and an impact number.

Build plan
Here is my project card: [paste it]. Give me a build plan for Claude in five steps: Project, skill, artifact, scheduled task, test. Two lines for each step. Do not build anything yet.
Check three figures
List three figures from my output and the exact rows they come from in the source file, so I can check them by hand. Do not change anything.
Project card
Department: [your department pack, or your own team]
Task: [what the agent does, in one line]
Input: [the file it reads; today it lives inside the skill]
Instruction: [the steps and two rules; what to do when unsure]
Output: [the artifact: a dashboard, a report or a deck, and its layout]
When: [the schedule, for example every Sunday at 08:00]
Who reviews: [one person's role or name]
Impact: [minutes by hand] - [minutes with the agent] x [runs a month]
Demo script
Write a 3-minute demo script for my project: the problem, the card, a live run, the artifact, the impact ((minutes by hand minus minutes with the agent) times runs a month), and what I would automate next. Use only facts from my files and runs.
Finished early? Extra task
  • Share your skill with a colleague from the same department and ask them to break it.
What to look forBuild in order: card, Project, skill, artifact, schedule. Check before you polish.
FilesNo file needed.
TakeawayCard, Project, skill, artifact, schedule, review: one agent.
