Outcomes

What you will be able to do.

  • Day 1 · Explain why an AI model can give a wrong date or number, and how a file and a clear instruction prevent it.
  • Day 1 · Use four questions to find the tasks in audit and onboarding that are worth automating.
  • Day 1 · Design an agent with a clear input, instruction and output.
  • Day 1 · Build a working agent in a Claude Project and run it on a real case file.
  • Day 1 · Test the agent with three cases and fix the instruction, not the answer.
  • Day 2 · Explain how a trigger, a workflow and an integration turn an agent into a system.
  • Day 2 · Build an n8n workflow that connects a form, Claude and a result page.
  • Day 2 · Ask Claude for named fields so the workflow can route each case.
  • Day 2 · Adapt the workflow to your department's task and rules.
  • Day 2 · Present your solution and choose the next task to automate, with an owner and a review rule.
The habit

Input, instruction, output.

The agent does the first pass. You sign the file.

  • Input. Name the exact file and the fields the agent reads.
  • Instruction. Role, steps, rules, what to do when unsure, output.
  • Output. A fixed format a reviewer can check in two minutes.
