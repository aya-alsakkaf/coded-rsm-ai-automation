Outcomes

What you will be able to do.

  • I can explain what generative AI does well and where it can be wrong, and check its output against the source.
  • I can find the tasks in my work that suit an agent, and describe one as an Agent Card: input, instruction and output.
  • I can build a Claude Project with instructions and knowledge that gives the same, checkable result on every run.
  • I can connect an agent to a Drive folder and have it return its output in a fixed format.
  • I can package my method as a skill and run it on a schedule, with a human review step.
  • I can match each Claude feature to its equivalent in ChatGPT, Microsoft 365 Copilot and Gemini.
How the days run

Claude does the first pass. You review.

Five habits from the two days:

  • One card. Input, Instruction, Output. Then When.
  • Five parts. Role, Steps, Rules, Output format, When unsure.
  • Flag, never guess. A missing field is written as Not found.
  • Drafts only. A named person reviews before anyone relies on it.
  • Dummy data. No client data in any tool RSM has not approved.
