Build your agent, step by step

Work through the steps as the day goes. Your notes and done marks stay in this browser. Paste your card to the shared board when the trainer asks.

Step 1

Your task inventory (Task 1.3)

  1. List 10 tasks from your last week.
  2. Tag each one: repeats weekly, clear rules, document in and document out.
  3. Preparers: what do you rebuild on every engagement? Reviewers: what do you check every time? Coordinators: what do you chase every week, such as requests or new-client KYC files?
Show a hint

If a task needs a meeting or a judgment call, it is not your first agent.

Saved in this browser only. The trainer checks it with you.
Step 2

Build the invoice agent with the trainer (Task 1.4)

  1. Projects, + New Project: Mirqab invoice match.
  2. Set project instructions: paste the five parts from the prompt sheet.
  3. Add mirqab-invoice-match-template.xlsx to the knowledge.
  4. Run it on the October invoices and ledger.
Show a hint

At least two rows should not say Matched. Look at the amount on page 3.

Step 3

Find the cut-off item

  1. Look at the row the agent marked Not in ledger.
  2. Check its date on the invoice. Is it in the October ledger?
Show a hint

It is the last invoice in the pack.

Step 4

Agent Card v1 (Task 1.5)

  1. Write your card: Input, Instruction, Output. Leave When empty.
  2. Paste it on the shared board for approval.
Show a hint

Read your Instruction box as if you were new. Would you know what to do?

Saved in this browser only. The trainer checks it with you.
Step 5

Build v1 of your agent (Task 1.6)

  1. Create your own Project. Write the five parts.
  2. Add a template or one example output to the knowledge.
  3. Check 3 items of your pack by hand (the list is in Task 1.6). Run the agent and compare.
Show a hint

Fix the instructions, not the answer.

Saved in this browser only. The trainer checks it with you.
Step 6

Read from the folder (Task 1.7)

  1. Customize, then Connectors: connect Google Drive.
  2. Run your agent on your track folder's Inbox. Ask it to list the files it read.
Show a hint

The folder path must match the Drive exactly.

Saved in this browser only. The trainer checks it with you.
Step 7

Same shape every run (Task 1.8)

  1. Add an output rule: exact columns, order and a total line.
  2. Run twice and compare.
Show a hint

Name the columns in the order you want them.

Saved in this browser only. The trainer checks it with you.
Step 8

Make your skill (Task 1.9)

  1. Ask Claude to turn your Project into a skill. Save it.
  2. Test it in a new chat outside the Project.
  3. Add one line to your card: where this skill would live in ChatGPT, Copilot or Gemini.
Show a hint

A skill needs a short name and one line on when to use it.

Saved in this browser only. The trainer checks it with you.
Step 9

The messy sample and the clock (Task 1.10)

  1. Run your skill on the messy file for your track. It hides a gap the agent must flag (the invoice file has two). No two values in it conflict.
  2. Log the minutes by hand and with the agent on the board.
Show a hint

A good agent flags what it cannot see.

Saved in this browser only. The trainer checks it with you.
